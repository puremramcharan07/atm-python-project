# ATM Python Project

A Python-based ATM application developed using Tkinter GUI.

## Features

- PIN Authentication
- Balance Enquiry
- Cash Deposit
- Cash Withdrawal
- PIN Change
- Mini Statement
- Saving and Current Account Selection

## Technologies Used

- Python
- Tkinter
- Object-oriented programming concepts
- GUI programming

## Project Files

- `atm_gui.py` – Handles the ATM graphical user interface.
- `atm_logic.py` – Handles ATM operations such as balance, deposit, withdrawal, PIN change and transactions.

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python atm_gui.py
